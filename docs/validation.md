## 免费额度优化

2026-10-13：首页等级汇总改为先聚合后关联，公开 GET 加入 Cache API 共享缓存，收藏改为批量加载和页面内筛选。没有新增数据库迁移、KV 或付费服务，也没有部署生产。

- 生产构建、13 项 TypeScript 测试及临时 Worker/D1 集成检查通过。验证了缓存命中不访问数据库、列表默认参数规范化、筛选/分页缓存隔离、TTL 过期、浏览器剩余缓存时间、缓存失败回退、管理操作后的本节点失效，以及错误与私有接口不缓存。
- 集成检查确认真实 Cache API 响应从 MISS 变为 HIT；批量详情保留完整出处、过滤缺失/隐藏条目、支持 80 个 ID，拒绝无效 ID 与超长批次。下架后原批量缓存与首页统计在本节点同时失效。
- 收藏单元检查确认 200 个 ID 分为 80/80/40 三批；复用普通列表数据、合并并发请求，分页/搜索/排序使用已加载快照。缺失资料短期记忆，网络失败可重试，过期后重新加载，旧在途请求不会覆盖手动重试的新结果。
- `npm run test:quota` 在真实本地 D1 中生成 500 条测试资料（含 hidden/expired），新旧汇总结果完全一致；原查询读取 8,334 行，优化后 968 行，减少约 88%。该回归检查已加入 CI。

未验证真实 Cloudflare 节点缓存命中率、生产流量与 Worker CPU 时间。Cache API 按数据中心生效，命中仍占 Worker 请求额度；其他节点的内容最多缓存 60 秒，目录/来源汇总最多缓存 300 秒。已经打开的收藏快照不自动轮询；返回收藏时检查鲜度，刷新页面也可重新加载。上线后需结合 D1 Row Metrics 和 `X-Atlas-Cache` 观察实际用量，不能把本地测试理解为保证所有流量都在免费额度内。
