# iPad 与手机交互验证

日期：2026-10-12。环境：本地 Workers / D1，Codex 内置浏览器的视口模拟。这里的“通过”指浏览器中的布局、DOM 尺寸与操作结果，不代表已经在真实 iPadOS / iOS Safari 上验证。

九种尺寸的页面 scrollWidth 均等于视口宽度，没有页面级横向溢出。复制、收藏、游戏跳转、筛选、排序、搜索输入的 DOM 区域高度均至少 44 CSS 像素；尺寸按最近整数像素记录，避免平移产生的浮点误差。搜索与选择输入字体至少 16px。明细保存在 [responsive-audit.json](responsive-audit.json)。

## 实际操作与修复

| 操作 | 验证结果 |
|---|---|
| 等级切换 | 手机选择 TH17 / TH18，列表与标题跟随更新；横屏抽屉能滚动并选到 TH1，选完自动关闭 |
| 搜索 | TH17 搜索 Hydra 显示空态；TH18 搜索 Hydra 返回 1 套配兵；清空后恢复 2 套 |
| 用途与排序 | iPad 可操作全部用途、部落战与最早收录；选中用途提供 aria-pressed 状态 |
| 分页 | iPad 全部阵型 32 条，进入第 2 / 3 页；翻页后结果标题位于视口 y=88，避免停留在页面底部 |
| 收藏 | 收藏后入口数量更新，刷新后仍在；进入收藏会清除旧搜索、用途及等级筛选；已取消测试收藏 |
| 收藏时浏览稳定性 | 普通资料列表收藏/取消时卡片保持可见，不出现 skeleton，不再触发整页重载 |
| 复制 | 显示“游戏链接已复制”；读取浏览器剪贴板，与详情原始分享链接完全相同 |
| 无分享链接 | TH3 的“暂无分享链接”按钮禁用，没有可误点的复制操作 |
| 长详情 | 滚到底仍可看见 44px 高的关闭按钮，手机下距视口顶部约 21px；出处地址正常换行 |
| 详情退出 | 关闭后解除背景滚动锁，恢复原列表位置；一次实测前后均为 scrollY=520.5 |
| 弹窗与导航 | 原生 dialog 保持焦点在弹窗内，Escape 可退出；导航切换至来源时只保留一个弹窗 |
| 旋转 | 抽屉打开时切到横屏常驻侧栏，抽屉关闭且解除滚动锁，列表筛选与分页状态保留 |

修复前，手机收藏按钮为 24×24px、搜索文字 9px，复制按钮约 30px 高；长详情关闭按钮滚动后位于屏幕之外。现在手机使用单列，iPad 按可用宽度使用双列或三列；主要操作至少 44px 高，详情采用固定工具栏与独立内容滚动。窄屏导航改用原生模态弹窗，短横屏滚动整个菜单。

已经添加刘海/底部安全区间距、触屏按下反馈、粗指针下取消悬停位移，以及减少动态效果偏好的兼容样式。浏览器模拟不能证明这些设置在真实设备上全部生效。

## 真机验证范围

上线前仍需用真实 iPad 和 iPhone 完成下列操作；当前没有把这些项目标记为通过：

1. Safari 软键盘弹出/收起、中文输入与搜索清空，确认没有自动放大或遮挡。
2. 惯性滚动、弹窗边缘滚动、横竖屏与 Safari 地址栏收起，确认背景锁定及关闭后位置恢复。
3. 刘海与 Home 指示条安全区、双指缩放、文字放大、VoiceOver 阅读顺序及真实粗指针反馈。
4. HTTPS 生产环境的剪贴板授权及拒绝后的手动复制路径。
5. 点击“在游戏中打开”，确认本机客户端接管、区服兼容以及游戏内导入结果。

## 扩充来源后的复核

2026-10-12：本地数据扩充到 421 个阵型、42 套配兵后，复核 820×1180 iPad 和 390×844 手机视口。iPad 来源总览显示五来源及成功状态，TH18 共 51 阵型、5 套配兵，阵型分页可从第 1 页进入第 2 页；新增来源与 Layouts 的可见图片均已加载。页面宽度等于视口，来源弹窗内部无横向溢出。

手机新增 Clashcodes 阵型详情图片正常显示，长标题换行，出处原始 URL 和采集时间可读；独立内容滚动到底后关闭按钮仍可见且高 44px，关闭后无打开的弹窗并恢复背景滚动。最终控制台无错误。证据见 [iPad 来源总览](preview-expanded-sources-ipad.jpg) 和 [手机阵型详情](preview-expanded-base-phone.jpg)。本次为浏览器视口模拟，真机待测范围仍适用。
